# Project Data Mining: DBLP Conference Popularity & Association Pattern Mining

## Setup Environment & Instalasi

1. **Clone repository** dan masuk ke direktori proyek:
```bash
git clone <url-repo-anda>
cd IF4041-project-data-mining
```

2. **Buat dan aktifkan virtual environment (`.venv`)**:
* **Windows (PowerShell):**
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

* **Linux / macOS / WSL:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. **Instal seluruh dependency**:
```bash
pip install -r requirements.txt
```
